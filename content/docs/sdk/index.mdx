XecureCode SDKs capture structured runtime errors and send non-blocking
telemetry to the ingest API. They also carry deployment metadata, fingerprint
data, and occurrence counts so the backend can group incidents correctly.

## Supported SDKs

| SDK | Status | Guides |
| --- | --- | --- |
| Node.js | Implemented | [Node.js](/docs/sdk/node) |
| Python | Implemented | [Python](/docs/sdk/python) |
| Java | Implemented | [Java](/docs/sdk/java) |

## Shared behavior

- Capture structured runtime errors.
- Generate deterministic fingerprints.
- Classify common error types.
- Detect severity.
- Send telemetry without blocking the host application.
- Support batched delivery when the host generates multiple errors quickly.
- Include deployment metadata when you have it.
- Keep recovery assistive and human-approved.
