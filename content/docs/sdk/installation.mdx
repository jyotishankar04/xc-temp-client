---
title: SDK installation
description: Install the XecureCode SDK for your runtime.
---

Choose the SDK that matches the service runtime. Keep API keys in server-side
environment variables and point the SDK at your backend API URL.

## Python

```bash
pip install x-reliability-sdk
```

Use [Python FastAPI](/docs/sdk/python/fastapi), [Python Flask](/docs/sdk/python/flask),
or [standalone Python](/docs/sdk/python/standalone) after installation.

## Node.js

```bash
npm install @xecurecode/reliability-sdk
```

Use [Node.js Express](/docs/sdk/node/express) or
[standalone Node.js](/docs/sdk/node/standalone) after installation.

## Java

```xml
<dependency>
  <groupId>com.xel</groupId>
  <artifactId>reliability-sdk</artifactId>
  <version>0.1.0</version>
</dependency>
```

Read the [Java SDK guide](/docs/sdk/java) for manual capture and Spring Boot
configuration.

## Production settings

- Set the API URL to your backend host, not `localhost`.
- Pass the service ID and API key from server-side secrets.
- Include the deployment version and commit hash when you deploy a release.
- Keep request and header redaction enabled in production.
