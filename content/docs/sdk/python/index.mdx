title: Python SDK
description: Install and configure XecureCode for Python services.
---

The Python SDK exposes `ReliabilityClient`, `ReliabilityConfig`, and framework
integrations for FastAPI, Flask, and Django.

## Install

```bash
pip install x-reliability-sdk
```

## Optional framework extras

```bash
pip install x-reliability-sdk[fastapi,flask,django]
```
