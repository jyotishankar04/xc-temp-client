---
title: Flask integration
description: Capture Flask errors with the Python SDK.
---

Initialize the Flask integration after creating the app and client.

```py
from flask import Flask
from reliability import ReliabilityClient, ReliabilityConfig
from reliability.flask_integration import init_flask

config = ReliabilityConfig(
    api_key="your-api-key",
    service_id="checkout-api",
    mode="production",
)

client = ReliabilityClient(config)
app = Flask(__name__)
init_flask(app, client)
```
