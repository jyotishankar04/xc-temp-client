XecureCode helps you capture production failures, group repeated incidents,
generate root cause analysis, recommend recovery actions, and keep humans in
control of rollback decisions.

## Platform flow

1. Create an organization and finish onboarding.
2. Create a service for each application and environment.
3. Generate an API key for the service.
4. Install an SDK and send failure events to XecureCode.
5. Use cases, RCA reports, actions, and audit logs to review recovery.

## Safety model

- SDK delivery is non-blocking.
- AI analysis runs asynchronously.
- Recovery actions need human approval.
- Audit logs preserve critical decisions.

## Authentication surfaces

Dashboard users sign in with GitHub OAuth. The frontend sends cookie-based
requests to authenticated `/api/v1` routes.

SDKs use service API keys when they send failure events to `/api/v1/ingest`.
